# Notebooks

The physical notebooks, and what has been done with each.

**Photograph a notebook completely before extracting anything from it.** Works
do not announce their boundaries on the page — a story may start mid-page,
run past a shopping list, and finish three pages later. Capturing the whole
notebook first means the paper only has to be handled once, and the ordering
question can be settled later on a screen rather than over the originals.

Track each one in `register.csv`. The point of the register is to answer, at a
glance, which notebooks are photographed, which are transcribed, and where the
physical book currently is.

## Photo naming

`<notebook-id>-p001.jpg`, numbered in reading order, every page including the
blank ones. Consistent zero-padded numbers keep the files sorting correctly
and let a transcript's `[[p012]]` marker point at exactly one photo.

## Where the photos live

Not in this repository — it stays text-only. Put them in Drive (and on
archive.org with the finished work). The `.txt` transcript is what git keeps.
